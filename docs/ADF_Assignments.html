Assignment 1Medium

Today’s CSV Landing — Filter by name + lastModified

Scenario

Vendor drops files in /landing/sales/. Copy ONLY .csv files modified TODAY into /bronze/sales/yyyy/MM/dd/.

Student files

Folder: ADF_Assignments/Assignment_01/
Upload landing/sales/* → ADLS /landing/sales/
Includes: sales_orders_a.csv, sales_orders_b.csv, sales_meta.json, readme_vendor.txt
Re-upload CSVs on lab day so lastModified = today.

Activities

Get MetadataFilterForEachCopy

Build

  1. Get Metadata Child Items on landing/sales
  2. Filter: File + endswith .csv + lastModified date = today
  3. ForEach → Copy; sink with concat yyyy/MM/dd; source = @item().name

Expression challenges

1. Filter only CSV modified today
endswith + equals(formatDateTime(lastModified), formatDateTime(utcnow()))
2. Sink folder with concat + formatDateTime
concat('bronze/sales/', formatDateTime(utcnow(),'yyyy'), '/', ...)

Acceptance

  • JSON/TXT ignored; only today’s CSVs in dated bronze folder

Stretch

If zero files, succeed with message (do not fail).
Assignment 2Medium

Lookup file list → If exists → Copy (replaces watermark)

Scenario

Control CSV lists which order files to load. Lookup the list, ForEach FileName, Get Metadata exists, If exists → Copy to /bronze/orders/yyyyMMdd/, else skip. Do not copy files that are in landing but not in the control list.

Student files

Folder: ADF_Assignments/Assignment_02/
control/files_to_process.csv → /control/
landing/orders/*.csv → /landing/orders/
Control lists west, east, south, ghost (missing on purpose).
Landing also has orders_north.csv (NOT in list → must not copy).

Activities

LookupForEachGet MetadataIfCopy

Build

  1. Lookup files_to_process.csv (all rows)
  2. ForEach → Get Metadata exists on landing/orders/@{item().FileName}
  3. If exists → Copy; else skip
  4. Sink: concat('bronze/orders/', formatDateTime(utcnow(),'yyyyMMdd'))

Expression challenges

1. Dynamic path from item().FileName
concat('landing/orders/', item().FileName)
2. If using exists
@equals(activity('GetMeta').output.exists, true)

Acceptance

  • west/east/south copied; ghost skipped; north not copied

Stretch

Collect missing names into an array variable.
